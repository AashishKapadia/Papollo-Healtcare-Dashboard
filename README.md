The Papollo Healthcare Dashboard is an interactive healthcare analytics project developed to provide a clear and comprehensive view of hospital operations, patient-related information, and key healthcare performance indicators. The project transforms healthcare data into meaningful visual insights through an interactive Tableau dashboard, helping users understand operational trends and make data-driven decisions.

The dashboard is designed to present complex healthcare information in a simple and visually engaging format. It allows users to analyze important aspects of hospital performance and explore patterns within the available healthcare dataset.

The project repository includes the Tableau packaged workbook (.twbx), the Papollo Healthcare dataset in Excel format, and a portfolio report, making the project suitable for demonstrating practical skills in data visualization and business intelligence.

**Objective of the Project**

The primary objective of the Papollo Healthcare Dashboard is to convert raw healthcare data into actionable information using interactive data visualization.

**The dashboard aims to:**

Provide a centralized view of healthcare-related information.
Analyze important hospital and patient-related metrics.
Identify trends and patterns in the available data.
Make healthcare information easier to understand through visualizations.
Support data-driven analysis and decision-making.
Demonstrate the practical use of Tableau for healthcare analytics.
Key Features

The dashboard provides an interactive analytical environment where users can explore healthcare information through different visualizations and filters.

**Key features include:**

_1. Interactive Dashboard_
The dashboard combines multiple charts and analytical views into a single interface, allowing users to understand different aspects of the healthcare data without manually analyzing large datasets.

_2. Healthcare Data Analysis_
The project uses structured healthcare data stored in an Excel dataset. The dataset is connected to the Tableau workbook for analysis and visualization.

_3. Visual Analytics_
Different charts and visual elements are used to identify trends, compare values, and understand patterns within the data.

_4. Filtering and Exploration_
Interactive filters allow users to focus on particular portions of the dataset and analyze information according to selected criteria.

_5. Business Intelligence Approach_
Instead of presenting raw tables alone, the project converts data into visual insights that can support hospital management and operational analysis.
