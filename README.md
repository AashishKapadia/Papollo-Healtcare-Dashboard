## 📊 Project Overview

**Papollo Healthcare Dashboard** is an interactive healthcare analytics project developed using **Tableau**. The project transforms structured healthcare data into an interactive dashboard designed to make healthcare information easier to explore, compare, and interpret.

The project demonstrates how **Business Intelligence and Data Visualization** can be applied to the healthcare domain to convert raw data into meaningful insights.

The repository contains the Tableau packaged workbook, healthcare dataset, and portfolio documentation.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze healthcare-related data using interactive visualizations.
- Present important healthcare information through a centralized dashboard.
- Identify patterns and trends within the available healthcare dataset.
- Compare healthcare metrics across relevant categories.
- Support data-driven healthcare and operational analysis.
- Demonstrate practical Tableau and Business Intelligence skills.
- Create a portfolio-ready healthcare analytics project.

***📈 Dashboard Analysis***

The Papollo Healthcare Dashboard provides an interactive environment for exploring healthcare information.

The dashboard can be used to:

Monitor healthcare-related performance indicators.
Compare different categories within the dataset.
Identify trends and variations.
Explore information through Tableau filters.
Analyze healthcare information through interactive visualizations.
Convert raw healthcare data into an easy-to-understand visual format.

The exact KPI names and values should be interpreted from the Tableau workbook and underlying dataset. This README does not invent metrics that are not explicitly documented in the project.
